# Why this build has no front end

An integration manager needs the next decision, the accountable person and the evidence behind a claimed benefit. This build keeps those records in a database and lets a coding agent run the same commands a person can inspect.

npm run view renders three read-only dashboards. npm run docs renders steering packs and benefit evidence records in the colours and business name in brand.json. /new-view adds another read-only view. None of these pages changes records.

Midaxo provides a broader hosted acquisition platform. A screen supplies visual task editing, shared navigation and its own collaboration controls. This starter provides no mobile application, offline synchronisation, drag-and-drop planning, secure document room or live team collaboration. It is for operators working through commands with controlled access to the database. Enterprise DNA scopes the screens and integrations a managed installation needs.

You own the source and data. Hosting, agent subscriptions, operations and any additional development remain costs. Compare the working scope and those costs with your actual subscription before switching.
